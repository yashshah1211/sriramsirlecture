# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for your interest in improving the Simple Interest Calculator project.

## How to Contribute

1. **Share ideas:** Open a GitHub issue to suggest a new feature or enhancement.
2. **Report bugs:** Open an issue describing the problem, the expected behavior, and steps to reproduce it.
3. **Submit bug fixes:** Fork the repository, create a branch, and make a focused fix.
4. **Improve documentation:** Fix errors, clarify instructions, or add useful examples to the README.
5. **Propose enhancements:** Explain the benefits of your proposed change and submit a pull request.

## Submitting a Pull Request

1. Fork this repository.
2. Create a descriptive branch, such as `fix/input-validation`.
3. Make your changes and test them.
4. Commit your work with a clear message.
5. Open a pull request that describes your changes.

## Code of Conduct

Please follow the guidelines in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) when contributing.
