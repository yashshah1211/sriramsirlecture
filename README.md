# Simple Interest Calculator

A beginner-friendly Python project that calculates **Simple Interest** and the **Total Amount** payable or receivable based on the principal, annual rate of interest, and time period.

## Objective

Build a simple calculator that uses the basic simple-interest formula to help users understand how interest is computed.

## Formula

```text
Simple Interest (SI) = (Principal × Rate × Time) / 100
Total Amount = Principal + Simple Interest
```

Where:

- **Principal (P)** is the initial amount of money.
- **Rate (R)** is the annual interest rate in percent.
- **Time (T)** is the duration in years.

## Features

- Accepts principal, annual interest rate, and time in years.
- Calculates simple interest using the standard formula.
- Displays both the interest earned and the total amount.
- Checks for invalid or negative input values.

## Technologies Used

- Python 3 (no third-party libraries required)

## How to Run

1. Install Python 3.
2. Clone this repository or download `calculator.py`.
3. Open a terminal inside the project directory.
4. Run:

```bash
python calculator.py
```

5. Enter the requested values when prompted.

## Example

**Input**

```text
Principal amount: 10000
Annual interest rate (%): 5
Time (years): 2
```

**Calculation**

```text
Simple Interest = (10000 × 5 × 2) / 100 = 1000
Total Amount = 10000 + 1000 = 11000
```

**Output**

```text
Simple Interest: 1000.00
Total Amount: 11000.00
```
